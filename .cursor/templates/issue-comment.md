# Шаблон комментария к issue / PR (существенный)

Канон и исключения: `.cursor/rules/project-github-formats.mdc` (раздел Comments).

```markdown
**Итог:** одна фраза
**Подробно:** факты, sha, шаги, без секретов
**Дальше:** следующий шаг или «нет»
```

Безличные формулировки: без личных имён, без ролей как имён людей, без «я/мы сделали». Обычный текст: «взято в разработку», «ветка `…`», «PR #NN». Если без этого неясно, можно назвать настроенную автоматическую проверку или автоматический прогон как участника процесса (проверка оставила замечание, автоматический прогон запушил ветку).
Уже опубликованные комментарии не переписывать без нужды; delete+repost только чтобы убрать запретную утечку (личное имя, роль как имя человека, имя чат-бота из закрытых чатов, секрет).
