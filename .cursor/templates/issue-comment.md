# Шаблон комментария к issue / PR (существенный)

Канон и исключения: `.cursor/rules/project-github-formats.mdc` (раздел Comments).

```markdown
**Итог:** одна фраза
**Подробно:** факты, sha, шаги, без секретов
**Дальше:** следующий шаг или «нет»
```

Безличные формулировки. Не называть исполнителей, агентов, ботов, облачные прогоны и инструменты: «взято в разработку», «ветка `…`», «PR #NN».
Уже опубликованные комментарии не переписывать без нужды; delete+repost — только чтобы убрать запретную утечку (упоминание агента и т.п.).
