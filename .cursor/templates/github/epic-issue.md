# Epic issue
Labels: `тип: родительская`, `статус: очередь`. Field «Тип» = «Эпик». «Приоритет» set at once. Rules: [epic](../../elements/issues/epic.md).

Title: `эпик(<сервис>): <цель кратко>` (service usually `общее`).

```markdown
## Зачем
<какую бизнес-проблему решает эпик, одним абзацем>

## Что сделать
Пройти маршрут эпика: бизнес-анализ, архитектура, разбиение на фичи. Текст разделов на странице вики.

## Критерии приёмки
- [ ] На странице эпика есть исходные пожелания, зафиксированные ожидания, архитектура и разбиение
- [ ] Все дочерние фичи в статусе «готово»
- [ ] Приёмка эпика владельцем по зафиксированным ожиданиям (и по эталону, если он есть)

## Связи
- Страница: [Epic-<Name>](https://github.com/PlutoGr/TravelAgency/wiki/Epic-<Name>)
- Дорожная карта: [Plan-Roadmap](https://github.com/PlutoGr/TravelAgency/wiki/Plan-Roadmap)
- Связанные эпики: #NN или «нет»
```
