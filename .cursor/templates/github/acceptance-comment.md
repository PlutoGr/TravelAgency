# Acceptance comment
One comment per acceptance run on dev. Rules: [Приёмка](../../lifecycle/11-deploy-and-acceptance.md).

```markdown
**Итог:** приёмка на dev пройдена | не пройдена.
**Подробно:** деплой `<sha>`. Проверено: <лёгкая проверка среза; глубокая ручная только для auth, денег, безопасности или сверки с эталоном>. <ТК-n пройден, если на странице есть номера кейсов; иначе политика тестов и что смотрели>. Сверка с ожиданиями эпика — на демо эпика.
**Дальше:** <«нет» | исправление в этой фиче | баг-фича #NN; задача остаётся в «Приёмка»>.
```

Non-product issue (criteria pass, no feature case ids; [non-product work](../../lifecycle/non-product-work.md)):
```markdown
**Итог:** критерии приёмки выполнены.
**Подробно:** <критерий: факт; критерий: факт>; PR #<PR> (или «без PR»); деплой `<sha>` (только если критерии требуют проверки на dev); документация: <`Doc-` страница | «вики не затронута»>.
**Дальше:** колонка «Готово», задача закрыта; при переоткрытии вернуть колонку «<Приёмка | Разработка | колонка ответа>».
```
