# Status comments
Posted by the orchestrator on every transition, then the label is set. This is the recorded gate verification. Rules: [columns](../../elements/board/columns/README.md).

Take from Очередь:
```markdown
**Итог:** взято в работу, колонка «<колонка>».
**Подробно:** страница [<Page>](<url>), ветка `<type/NN-slug>` (если есть).
**Дальше:** <что готовится в этой колонке>.
```

Stage advance:
```markdown
**Итог:** колонка «<колонка>» принята, следующая «<колонка>».
**Подробно:** проверено: <критерии выхода по пунктам>; раздел [<раздел>](<url>#<якорь>).
**Дальше:** <следующая работа>.
```

Owner question (with `статус: на ревью`):
```markdown
**Итог:** нужно решение владельца.
**Подробно:** <вопрос>; варианты: <А>, <Б>; рекомендация: <вариант и почему>.
**Дальше:** после ответа вернуть колонку «<колонка>».
```

Decision recorded:
```markdown
**Итог:** решено: <решение>.
**Подробно:** строка «Решения» от <дата> на странице [<Page>](<url>#решения).
**Дальше:** колонка «<колонка>» восстановлена.
```

Hold:
```markdown
**Итог:** задача на удержании.
**Подробно:** <причина>.
**Дальше:** <что снимет удержание>, вернуть колонку «<колонка>».
```
