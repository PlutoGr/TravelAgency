# Status comments
Posted by the orchestrator on every transition. In the same turn: the comment text first, then label and board Status; for Готово the issue close is last. This is the recorded gate verification. Rules: [columns](../../elements/board/columns/README.md).

Take from Очередь:
```markdown
**Итог:** взято в работу, колонка «<колонка>».
**Подробно:** страница [<Page>](<url>), ветка `<type/NN-slug>` (если есть).
**Дальше:** <что готовится в этой колонке>.
```

Stage advance:
```markdown
**Итог:** колонка «<колонка>» принята, следующая «<колонка>».
**Подробно:** проверено: <критерии выхода по пунктам>; раздел [<раздел>](<url>#<якорь>).
**Дальше:** <следующая работа>.
```

Owner question (issue **stays** in the current column; pause in [memory](../../elements/memory.md)):
```markdown
**Итог:** нужно решение владельца; колонка «<колонка>» без смены.
**Подробно:** <вопрос>; варианты: <А>, <Б>; рекомендация: <вариант и почему>.
**Дальше:** после ответа продолжить «<колонка>».
```

Decision recorded:
```markdown
**Итог:** решено: <решение>.
**Подробно:** строка «Решения» от <дата> на странице [<Page>](<url>#решения).
**Дальше:** продолжить колонку «<колонка>».
```

Close (→ Готово; then the issue is closed):
```markdown
**Итог:** колонка «Готово», задача закрыта (выполнено | не планируется).
**Подробно:** проверено: <критерии выхода>; PR #<PR> (или «без PR»); страница [<Page>](<url>) «сделано» | «отменено»: <причина>.
**Дальше:** при переоткрытии вернуть колонку «<одна колонка: Очередь для «не планируется», в том числе эпика; Приёмка для фичи после приёмки; колонка закрытия для задачи вне продукта; В работе для эпика, принятого из «Демо»>».
```

Hold (long work-stream pause → `статус: удержание`):
```markdown
**Итог:** задача на удержании.
**Подробно:** <причина; чьё решение>; для эпика: приостановлены <#NN, #NN>.
**Дальше:** снимет удержание: <обязательно: конкретное условие или решение владельца>; вернуть колонку «<колонка>».
```
