# Branch name
Rules: [branches](../../elements/git/branches.md).

```
<type>/<NN>-<short-english-slug>
```
`type`: `feature` | `fix` | `docs` | `infra` | `chore` | `deps`. Create: `gh issue develop <NN> --name <type>/<NN>-<slug> --base main`.

Examples: `feature/101-client-profile-ui`, `fix/218-refresh-token-security`, `docs/303-issue-templates`, `infra/318-actions-english-names`.
