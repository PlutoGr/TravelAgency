# Issue or PR comment
For every substantial comment. Rules: [issues](../../elements/issues/README.md). On a review thread a short reply is enough ([review replies](review-replies.md)).

```markdown
**Итог:** <одна фраза: принято / найдена причина / решение / нужна доработка>
**Подробно:** <факты, sha, шаги, без секретов>
**Дальше:** <следующий шаг или «нет»>
```

Example:
```markdown
**Итог:** принято.
**Подробно:** проверено на dev, коммит `a078d3c`. Refresh сразу после входа отвечает 200, после выхода тот же токен даёт 401.
**Дальше:** нет.
```

Impersonal: «взято в разработку», «ветка `…`», «PR #NN»; no names, roles, agents, «я/мы». Cursor Automations may be named when needed.
