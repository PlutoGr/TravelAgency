# На ревью (`статус: на ревью`)
**Only for epic (or feature) owner acceptance after the work is done**: the demo gate before Готово ([stage 13](../../../lifecycle/13-epic-acceptance.md)). Not a code-review column. Not a parking place for owner questions.

- **Applies to:** epic after every listed child is Готово; rarely a feature if the owner must accept that slice before Готово.
- **Enter:** with the [epic demo](../../../templates/owner/epic-demo.md) / owner-acceptance path. Record in [memory](../../memory.md).
- **While here:** the owner accepts or names gaps; other unblocked work continues.
- **Leave:** → Готово on pass; → В работе on gaps (epic). Never restore a feature to В работе.
- **Owner question mid-stage:** stay in the current column; see [Удержание](on-hold.md) and [memory](../../memory.md).
- **Who moves:** orchestrator.
