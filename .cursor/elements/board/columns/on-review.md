# На ревью (`статус: на ревью`)
An interrupt, not a review column and not the next stage after Тест-кейсы.
- **Applies to:** any item while the owner must decide; an epic also for owner epic acceptance after every child is Готово.
- **Enter:** with the owner question comment that names the column to restore ([status comments](../../../templates/github/status-comments.md), [owner question](../../../templates/owner/owner-question.md)).
- **While here:** the owner decides; other unblocked work continues.
- **Leave:** after the answer, record «**Итог:** решено: ...» (and the «Решения» row) and restore the recorded column. Epic acceptance: → Готово on pass, → В работе on gaps. Never restore a feature to В работе.
- **Who moves:** orchestrator.
