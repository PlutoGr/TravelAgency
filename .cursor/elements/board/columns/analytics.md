# Аналитика (`статус: аналитика`)
- **Applies to:** feature, bug-feature.
- **Enter:** take from Очередь (sets the epic to В работе if this is its first child in flight; never #8 — the standing backlog stays in Очередь for life).
- **While here:** an analyst cloud agent drafts section «Бизнес и сценарии»; the orchestrator reviews and publishes ([Аналитика](../../../lifecycle/06-feature-analytics.md)).
- **Leave:** → Архитектура when the stage gate passes. Owner question: stay here, `Question` in [memory](../../memory.md#question).
- **Who moves:** orchestrator, with the stage comment.
- **Required:** section «Бизнес и сценарии» meets its bar on the `Feature-` page.
