# Приёмка (`статус: приёмка`)
- **Applies to:** feature, bug-feature; non-product issue when dev acceptance applies.
- **Enter:** after merge and a green Deploy to dev whose deployed sha includes it ([Приёмка](../../../lifecycle/11-deploy-and-acceptance.md)).
- **While here:** the orchestrator does a light check on dev (deep manual only for auth, money, security, or a visual that must match the etalon) and posts the [acceptance comment](../../../templates/github/acceptance-comment.md). Full comparison to epic expectations waits for the epic demo. Tiny misses are fixed here (a fix PR keeps `статус: приёмка`); substantial misses become bug-features while this issue stays open; when the PR named a `Doc-` page, that page is current before leave ([Doc- after merge](../../../lifecycle/12-docs-after-merge.md)): Малая from the PR draft, Крупная from the after-merge draft.
- **Leave:** → Готово when the [Приёмка](../../../lifecycle/11-deploy-and-acceptance.md) exit holds (light check, deep check when required, named `Doc-` or «вики не затронута»; a non-product issue: its criteria). → Разработка when a green Deploy (a rollback) no longer contains the row's match sha ([row lifecycle](../../memory.md#row-lifecycle)).
- **Who moves:** orchestrator.
- **Required:** acceptance comment naming what was checked (case ids when the page has them); a non-product issue uses the criteria pass comment ([acceptance comment](../../../templates/github/acceptance-comment.md)).
