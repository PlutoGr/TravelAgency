# Разбиение (`статус: разбиение`)
- **Applies to:** epic only.
- **Enter:** from Архитектура.
- **While here:** an architect cloud agent drafts the feature list; the orchestrator publishes it and creates the child pages and issues ([stage 05](../../../lifecycle/05-epic-split.md)).
- **Leave:** → В работе when the first child leaves Очередь, normally in the same turn that accepts the split ([stage 05](../../../lifecycle/05-epic-split.md)).
- **Who moves:** orchestrator.
- **Required:** each split line has a `Feature-` page and a child issue in Очередь with «Приоритет».
