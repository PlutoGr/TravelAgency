# Архитектура (`статус: архитектура`)
- **Applies to:** epic. A feature or bug-feature does not enter. A feature found here moves forward by the [in-flight rule](../../../lifecycle/README.md#gates).
- **Enter:** epic from Бизнес-анализ ([epic Архитектура](../../../lifecycle/04-epic-architecture.md)). Refuse an epic while «Ожидания» are missing.
- **While here:** an architect cloud agent drafts «Архитектура». The orchestrator publishes. A later gap found on a child is fixed on this epic page, not by putting the feature in this column ([gap](../../../lifecycle/04-epic-architecture.md#gap)).
- **Leave:** epic → Разбиение after owner yes to `approve epic architecture #NN` ([epic Архитектура](../../../lifecycle/04-epic-architecture.md)). Owner question: stay here, `Question` in [memory](../../memory.md#question).
- **Who moves:** orchestrator, with the stage comment.
- **Required:** architecture section visible; every important choice logged in «Решения».
