# Архитектура (`статус: архитектура`)
- **Applies to:** epic and feature (bug-feature too).
- **Enter:** epic from Бизнес-анализ ([epic Архитектура](../../../lifecycle/04-epic-architecture.md)); feature from Аналитика ([feature Архитектура](../../../lifecycle/07-feature-architecture.md)). The architect refuses the column while the analysis bar fails.
- **While here:** an architect cloud agent drafts «Архитектура» and «Решения» rows; the orchestrator reviews and publishes.
- **Leave:** epic → Разбиение; feature → Тест-кейсы. Owner question: stay here, `Question` in [memory](../../memory.md#question).
- **Who moves:** orchestrator, with the stage comment.
- **Required:** architecture section visible; every important choice logged in «Решения».
